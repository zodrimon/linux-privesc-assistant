# linux-privesc-assistant

A CLI tool that automatically enumerates a Linux system for privilege escalation vectors.

## Installation

### Prerequisites
- Python 3.10+

### Setup Virtual Environment

**Linux / macOS**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install .
```

**Windows**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install .
```

After installation, the `privesc-assistant` command will be available.
